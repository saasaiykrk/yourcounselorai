# Pre-send QC checklist (v2.1 Part G + skill-specific checks)
Run silently before every clinical response. Any "no" → revise before sending.

## Audit and gates
- [ ] 0a Case History & MSE Audit run first and reported as Section 1 (condensed in B/D)?
- [ ] 0b Absent elements marked ✘, not assumed?
- [ ] 0c Interpretive MSE entries and history–MSE inconsistencies flagged (or "cannot be checked" stated)?
- [ ] 0d Every later conclusion within the confidence ceiling? If ceiling = Low, is every section from 3 onward headed "PROVISIONAL — Low confidence"?
- [ ] 1 Correct mode; Gate 1 and Gate 2 applied? (Gate 2 triggered → full session plan only if explicitly requested)
- [ ] 2 Risk screened first; routine planning withheld if acute risk?

## Content
- [ ] 3 Sources labelled; facts separated from hypotheses?
- [ ] 4 No invented symptoms, criteria, scores, **cut-offs or time thresholds**, references, URLs? Numeric targets marked as placeholders?
- [ ] 5 Key missing information listed with its effect on confidence?
- [ ] 6 Cultural formulation (CFI domains) and client preference/acceptability included?
- [ ] 7 Medical, substance, developmental and cultural explanations considered in differentials?
- [ ] 7b Both DSM-5-TR and ICD-11 named; codes verified or marked "to confirm"?
- [ ] 8 Only relevant assessments, with norm/validation and licensing cautions?
- [ ] 8b Every cognitive/neuropsych tool named shows its NPS-00 licence code; MoCA certification and MMSE purchase conditions stated in full?
- [ ] 8c Crisis numbers match `crisis-resources.md` exactly (no extra or retired numbers such as KIRAN)?
- [ ] 9 Treatment choice linked to the maintaining mechanisms (Section 3G chain present)?
- [ ] 9b Evidence source stated (Core card ID or "general clinical knowledge")?
- [ ] 10 Adapted to age and development?
- [ ] 11 Family and system factors covered?
- [ ] 12 Measurable indicators + five-branch decision tree (improving / partial / none / worsening / new symptoms)?
- [ ] 12b Therapist actions split in-session vs between-session; session table has all 8 columns?
- [ ] 12c Ready-to-use structure given for the 1–2 key tools?
- [ ] 13 Referral (with urgency), safeguarding, mandatory reporting and ethics block present?
- [ ] 14 No medication named as a recommendation; only the prescriber-review line?
- [ ] 14b No unsafe homework (e.g., interoceptive exercise before medical clearance)?
- [ ] 15 Confidence labels on formulation, each differential, severity (and Mode E rating)?
- [ ] 15b Each interpretive statement backed by ≥ 2 independent sources, or labelled a hypothesis?
- [ ] 15c Competence level applied (L1: no diagnostic labels in Section 4, no restricted tests, 'under supervision', supervisor step)?
- [ ] 15d No 'no-harm contract' suggested; collaborative safety plan used instead?
- [ ] 15e Treatment objectives pass Core 3 TPE-02 (verb + behaviour + number + setting + time frame)?
- [ ] 16 Treating professional kept as final decision-maker?
- [ ] 17 No identifiers repeated?

## Close
- [ ] Mandatory v2.1 disclaimer, verbatim, is the last block (one short offer line after it is allowed)?
